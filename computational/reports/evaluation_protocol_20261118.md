# 评估指标、参数与续跑方案

这些是内部保守计算筛选门槛，不是比赛官方规定，也不能换算成实验 KD。
比赛目标仍是最多 20 个新颖、配对的 IgG 候选；当前模型处理的是 VH/VL 与靶点复合物。

## 生成参数

- 靶点：人 IL4RA P24394-1 的 26–232，共 207 个残基；完整 canonical 序列。
- 抗体：5I19 通用人源配对框架；6 个 CDR 全部重新设计。已知 IL4RA 抗体不作为设计起点。
- 四个条件：表位 107/108/109 或 67/70；HCDR3 长度 12 或 16；已完成每条件 125 个，共 500 个。
- RFD4-Proteina 固定权重版本 `a06e2509c7033b010fc43614e9fd840303588502`。
- Native BF16、batch size 1、num_workers 0、eager execution。
- 原完整生成：60 步，medium/front_loaded，180 trunk passes。
- 主链采样 `tsr_k=16, tsr_sigma=3`；局部 latent 采样 `tsr_k=4, tsr_sigma=12`。
- 初轮随机种子 2026111700–2026111719；每批 25，20 批串行。

## 当前筛选标准

| 层次 | 指标与门槛 | 意义 |
| --- | --- | --- |
| 完整性 | 正确 T/H/L 链、靶序列、有限坐标、6 个 CDR 和成对框架 | 排除错误结构或输入 |
| 碰撞 | 靶点–抗体重原子距离 <2 Å 的原子对数为 0 | 排除明显穿插 |
| 表位覆盖 | ≥2 个指定热点在 5 Å 内；≥5 个靶点残基接触 | 覆盖设计表位 |
| CDR 参与 | ≥3 个接触 CDR 残基；CDR 占抗体接触残基 ≥50% | 识别面主要由 CDR 提供 |
| 几何保持 | 靶点主链偏差 ≤2.5 Å；配对框架 RMSD ≤2.5 Å | 避免靠结构畸变制造接触 |
| 糖基化风险 | 到注释糖基化位点 ASN ND2 的最小距离 ≥4 Å | 仅为风险代理，不等于完整糖链建模 |
| 序列风险 | CDR 额外 Cys 为 0；最终队列 CDR N-X-S/T（X≠P）为 0 | 排除部分化学/表达风险 |
| 独立复折叠姿态 | 对齐靶点后，整个 Fv 主链 RMSD ≤2.5 Å | 检查结合姿态能否被独立恢复 |
| 单链折叠置信度 | VH、VL 的平均 CA pLDDT 各 ≥80 | 检查抗体本身是否能折叠 |
| 靶点界面置信度 | 实际接触靶点的同一条 H 或 L 链，对 T 的 pair ipTM ≥60 且 min ipAE ≤2 Å | 不能拿 H–L 配对分数代替靶点结合 |
| 重轻链配对 | H–L pair ipTM ≥60 | 单独检查 VH/VL 配对 |
| 参考相似性 | 与已冻结参考抗体相比，六 CDR 相似度和 H3 相似度同时 ≥0.8 时排除 | 内部有限参考筛查，不是穷尽新颖性认证 |
| 候选多样性 | 最终候选间六 CDR 相似度 <0.8；最多 20 个 | 避免同一序列家族占满名单 |

本仓库将 ipTM 从 0–1 缩放到 0–100，因此表中的 60 等于常见写法 0.60。
pair min ipAE 是仓库输出的双方向汇总指标，不是整个界面的平均 PAE。
缺失复折叠结构或置信度属于运行/证据缺失，不能算科学通过或解释成不结合。

## 独立评价与本轮续跑

OpenFold3 使用完整 T/H/L 序列、仅提供靶点结构模板，不提供抗体结合姿态模板；
单序列运行，5 recycles、每次 1 个 diffusion sample。保存预测结构和链对置信度。

1. 两个随机种子（20261118、20261119）评价 6WGL 已知阳性对照。
   对照使用其 Fv 与本任务 canonical 靶点，不参与生成、优化或最终提交。
2. 对四个自研候选 b07_d014、b19_d014、b15_d019、b10_d019 用第二个种子复核。
3. 对照在两个种子下都恢复原设定的姿态与界面门槛后，才启动 32 个局部优化变体：
   每个自研母本 8 个，`partial_trajectory_fraction_steps=0.5`，保留原模型与 recycle 预设。
   这表示使用部分扩散轨迹，不表示 0.5 Å 扰动，也不等于“50% 序列突变”。
4. 每个母本最多选择 4 个合格且不重复的变体做独立复折叠，最多 16 个；用同一完整标准筛选。
5. 若对照未通过校准，则记录原因并停止扩增，不能自动把对照当成功或把标准调松。

用户已明确要求：本轮先按原标准运行，结束后如果仍没有候选，再讨论从已完成的设计池中
降低部分计算筛选门槛。当前没有实施放宽，也不会把原先失败的记录改写为通过。
